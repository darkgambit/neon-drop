Cascade strategy: how to build merge chains

Strategy guide

Most players lose at Neon Drop for the same reason: they merge the moment they can. Merging early feels productive, but it throws away the single biggest source of score in the game — the cascade. This guide explains exactly how cascades happen and how to set them up on purpose.

What a cascade actually is

When tiles merge, the board does not just settle once. The engine runs a loop:

  1. Apply gravity — every tile falls as far as it can.
  2. Look for touching groups of equal tiles and merge them.
  3. If anything merged, go back to step 1.

That loop is why one drop can produce a five-link chain. A merge creates a bigger tile where two smaller ones used to be, gravity shifts everything down, and the new arrangement may put that bigger tile next to an equal one — which merges again, and again, until the board is stable. Every extra link in the chain is worth dramatically more than the last.

Why chaining pays so much

The combo counter only resets when a drop finishes. Within a single settle loop it keeps climbing, and the multiplier is applied to every merge:

points = new tile value × (1 + combo × 0.25)
The first merge of a chain pays 1.25×, the second 1.5×, the third 1.75×, the fourth 2× and so on — and the tile values are doubling at the same time.

That compounding is the whole game. A single 2+2 merge into a 4 is worth 5 points. Chain three merges together in one drop — 2+2 into a 4, that 4 into an 8, that 8 into a 16 — and you collect 5 + 12 + 28 = 45 points, nine times as much, from the same three merges. Keep the chain alive one link longer and the numbers run away quickly.

The staircase: how to set a chain up deliberately

A chain happens when a merge produces a value that already touches an equal tile. So the shape you want in a column is a descending run — each tile double the one above it. Reading from the bottom of a column upward, that looks like this:

16
8
4
2

Now drop a 2 onto the top of that column. The two 2s fuse into a 4. That 4 is touching the 4 beneath it, so it fuses into an 8. That 8 is touching the 8 beneath it, so it fuses into a 16 — and if you have a 16 under that, the chain continues. One tile, four merges, and the combo multiplier climbing the whole way.

The same logic works sideways. Two 4s sitting side by side will merge the moment gravity drops something that lets them touch, so leaving deliberate pairs next to each other across neighbouring columns is a valid setup too.

Practical habits

  • Keep one column as your seed column. Build the descending run there and feed it. Leave at least one column empty for as long as you can — it is your escape hatch when the board gets tight.
  • Do not merge just because you can. Ask whether the merge sets up the next link or destroys a staircase you were building.
  • Watch the NEXT preview. It tells you what is coming, which is the difference between a plan and a reaction.
  • Big tiles change what you are dealt. The spawn pool is not fixed. Once you have a 32 on the board, 8s start appearing; past 128 you start seeing 8s and 16s; past 512, 16s and 32s. Building one tall tile therefore makes the rest of the game faster — and makes accidental chains more likely.
  • Respect the ceiling. A staircase needs vertical room. If a column is nearly full, you have no space left to feed it.

The failure mode to avoid

The board ends when all five columns are full and no two touching tiles are equal. That almost never happens suddenly. It happens because you spent twenty drops flattening the board with single merges and left yourself no structure. A staircase is not just a scoring trick — it is the thing that keeps your board from filling up.

Try it now: start a run and spend the first ten drops building one clean descending column instead of merging on sight. The difference in score is obvious almost immediately.
